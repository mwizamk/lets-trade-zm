# Let's Trade ZM

## v0.4.0 — Design Prototype

This release is the clean design-first starting point for the `lets-trade-zm` repository.

### Files

- `index.html` — complete responsive landing page.
- All CSS and JavaScript are intentionally inside `index.html` for this stage.

### Included

- Responsive landing page
- LET'S TRADE ZM branding
- Navy / deep-purple / bush-green / sky-blue / cream palette
- Service categories
- Netflix, Prime Video, Spotify and Showmax prototype cards
- Multiple service selection
- Live selected-service count
- Live total
- Mobile-friendly layout
- Three-step customer journey
- Support CTA

### Not connected yet

- Firebase
- Firestore
- Authentication
- Real PriceList data
- Customer records
- Orders
- Payments
- Payment verification
- Subscription activation
- Admin portal

Those will be added after the design is confirmed.

## GitHub Pages

Upload the contents of this package to the root of the `lets-trade-zm` repository.

Do not upload the outer ZIP folder itself as a nested repository folder.

For this release, the repository root should contain:

```text
index.html
README.md
```

Then commit the changes and use GitHub Pages from the repository's `main` branch and root folder.
